# Fight for $20

Source for fightfor20.com. Better wages. Stronger businesses.

The site is one static file, `index.html`. No build step. GitHub Pages serves it as is.

## Updating the site

Edits go in `index.html` and are committed here. Nothing goes live without the owner's OK.

Figures on the site come from the sources listed at the bottom of the page. Re-check any wage figure before publishing; local rates change every January and July.

FightFor20.com is an independent project. Not affiliated with any candidate, party or campaign.
